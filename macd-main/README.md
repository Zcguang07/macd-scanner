# 📡 MACD Multi-Timeframe Divergence Scanner (4H / 1D / 1W)

这是一个基于 Python 和 GitHub Actions 的全自动量化扫描系统，专注于监控美股核心股票池在 **4小时**、**日线** 和 **周线** 级别上的「MACD 面积顶底背离」形态。系统通过 Discord Webhook 实时推送右侧交易信号，辅助进行大波段的抄底与逃顶决策。

## 🧠 核心策略原理

本系统采用极其严苛的 **“动能面积衰竭”** 算法，有效过滤传统 MACD 背离中的假信号（骗线）。所有的波段抓取均包含严格的**零轴过滤**，确保只捕获真正的多空蓄力波段。

### 🟢 底背离 (抄底/做多)
当且仅当满足以下全部条件时触发：
1. **价格破新低** (`P2 < P1`): 当前绿柱极值点的价格，低于前一个绿柱极值点的价格。
2. **DIF 抬高** (`A2 > A1`): 当前绿柱的 DIF 最低点，高于前一波的 DIF 最低点。
3. **动能面积衰竭** (`B2 < 0.5 * B1`): 当前下跌波段释放的 MACD 绿柱总面积，萎缩至前一波的一半以下。

### 🔴 顶背离 (逃顶/做空)
将底背离逻辑完美倒置，寻找红柱波段：
1. **价格创新高** (`P2 > P1`)
2. **DIF 降低** (`A2 < A1`)
3. **动能面积衰竭** (`B2 < 0.5 * B1`)

## ⏱️ 运行与调度机制

系统完全托管于 **GitHub Actions**，实现零成本自动化运维。

*   **运行频率**: 工作日（周一至周五）每天运行两次。
*   **持久化记忆**: 引入 `sent_signals.json` 作为状态机。每个波段通过其起始时间 (`start_time`) 生成终生唯一的 ID，一旦触发通报，该 ID 将被写入备忘录。即使该形态在接下来的一周内持续存在，系统也**绝对不会重复轰炸**。
*   **信号保鲜期**: 为不同周期设定了严格的过期时间（4H有效期8小时，日线24小时，周线72小时），拒绝陈旧无效信号。

## 🗂️ 警报卡片格式

当检测到信号时，Discord 机器人将推送结构化的数据卡片：

*   **智能红绿灯**: 
    *   🟢 底背离：判断价格是否站上 20 EMA（右侧确认）。
    *   🔴 顶背离：判断价格是否跌破 20 EMA（右侧看跌）。
*   **多维共振**: 同步展示 200 SMA (牛熊分界线) 与 RSI(14) 的超买/超卖状态。
*   **动态目标**: 根据不同周期，给出合理的均值回归目标（周线看 20EMA，日线看 200SMA，4H看 250EMA）。
*   **极值止损**: 严格将止损位设定在绝对极值点的 1% 之外（底背离跌破前低 1% 止损，顶背离突破前高 1% 止损）。
